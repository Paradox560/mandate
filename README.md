# Mandate

Evidence-linked approvals for AI-generated equity orders. A paper-trading research workspace with deterministic tool permissions, Nicrron inference, PRISM observability and an auditable order ledger.

## Development

Node 22.13 or newer. Run `npm install`, copy `.dev.vars.example` to `.dev.vars`, then `npm run dev`. Secrets belong only in `.dev.vars` (ignored by Git). API keys are never exposed in the browser. All market prices are synthetic; historical issuer sources are labelled and dated.

This is a hackathon prototype. It cannot place real trades. Product differentiation, assumptions, validation and integration setup will be documented as implementation completes.
